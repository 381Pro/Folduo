# 0.1.14の公開前点検

2026年9月13日に、配布対象を開発用の作業場所から分離して確認しました。公開対象は自作ソース、ビルド定義、試験、設定補助、文書、Gradle Wrapper、依存ライブラリのライセンス表示です。

## 公開対象から除外したもの

- 端末シリアル、個人の画面、実機の録画・ログ・診断結果
- ローカルのユーザー名を含む設定、SDKの絶対パス、IDE設定、ビルドキャッシュ
- 署名の秘密鍵、認証情報、トークン
- Samsungの壁紙・動画・アプリ・ファームウェア、調査用に取得したコード
- AppleやSNS投稿者の画像・動画、以前の開発資料とAPK

公開用ソースから新しくGitの履歴を作ります。元の作業場所を丸ごと公開する構成ではありません。

## 検査結果

| 対象 | 確認した範囲 | 結果 |
| --- | --- | --- |
| ソース | Gitleaks 8.30.1による検査、ファイル一覧・文字列の点検 | 秘密情報の検出なし |
| 公開用APK | 展開したファイルとDEX中の文字列、資産の点検 | 秘密情報の検出なし。第三者の壁紙・録画なし |
| 公開用ビルド | Java 17、固定したGradle・AGP・SDKで別フォルダーから生成 | 成功 |
| 単体試験 | `testDebugUnitTest` | 32件成功、失敗・スキップなし |
| 静的検査 | `lintRelease` | エラー0件。既存の警告32件あり |
| 壁紙補助 | 公開したPythonスクリプトからJavaソースをコンパイルしDEX JARを生成 | 成功。今回の公開作業では壁紙の再変更はしていない |
| APKの署名 | Androidのapksignerによる検証 | 署名有効、従来の実機試験版と同じ証明書 |
| 既存0.1.14との比較 | アプリの全ソース、APKの実行コード・資産 | 実行コード・画面素材は同一。ライセンス8文書を追加し、Gitの検出状態を示すビルド管理情報のみ変更 |

Gitleaksは公開物に含めていない検査用ツールです。検出なしは、あらゆる秘密・脆弱性が存在しないことを保証するものではありません。

## 実機確認と未確認を分ける

公開前の同じ0.1.14実装はSM-F966Zへ導入し、壁紙経由で22度などの中間角度を受信し、開閉時の画像準備・遷移を繰り返すことを確認しています。公開用の再ビルドでは、DEX2ファイル・マニフェスト・画面素材がその実機版と同一であることを確認しました。公開用ファイルを別の利用者の初期状態の端末へ導入する一連の操作は、まだ検証していません。

別の型番・OS、長時間のケーブルなし運用、すべてのアプリ、内側の純正操作バーの完全復元は未確認または未対応です。Shizuku停止の根本原因は未確定です。既存の静的検査の警告をすべて解消した版でもありません。
