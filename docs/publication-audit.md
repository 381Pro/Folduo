# Folduoの点検記録

## Folduo 0.1.21 — 2026年9月15日

内側左画面の横方向の引き伸ばしを外し、元の幅を保って左端ほどぼける描画へ変更しました。上下の補正を穏やかにし、折り目の近くは絵が読み取りやすいぼかしにしています。前面の演出、画像交換、角度取得、操作の制御は0.1.17から変更していません。

| 確認項目 | 結果 |
| --- | --- |
| 配布APK | 0.1.21、versionCode 41。英語・日本語ともFolduo。同じ署名で実機更新 |
| 単体試験 | 35件成功 |
| Fold7のGPU・プレビュー試験 | 20件成功。180〜90度の8段階で図形の横輪郭を測定し、位置差は最大1px |
| ぼかし | 180〜90度を2度刻み、左端寄り・中央・折り目寄りで連続性を確認 |
| 静的検査 | エラー0件、警告34件 |
| 配布物の照合 | 実機から読み戻したAPKと配布APKのSHA-256が一致 |
| 秘密情報検査 | 公開ソース、Git履歴、展開したAPKと壁紙補助で検出なし |
| 未確認 | 最新の修正を実際に開閉した最終的な見え方、長時間の安定性 |

GPU試験は角度を入力して描いた結果の検証で、実際のヒンジを動かした外観の検証とは区別しています。個人の画面や未加工の端末ログは配布しません。壁紙補助の実行コードは0.1.17と同じです。

実機で照合したAPKをそのまま配布します。埋め込みのコミット情報はビルド時の比較元 `ee0ef8a` を示すため、対応するソースの版は `v0.1.21` タグを参照してください。

## Folduo 0.1.17 — 2026年9月14日

接続したFold7で、内側ホームの入力は届く一方、Samsungが新規アプリの起動を前面へ振り替えることを確認しました。Folduoにホーム画面を統合し、Shizuku経由で選んだアプリのタスクだけを内側へ移します。ホームへ戻る際も、選択中のホームを表示・再開します。各ディスプレイにあるホーム用の親タスクを重複させず、中のホーム画面を引き継ぎます。

| 確認項目 | 結果 |
| --- | --- |
| 実機への導入 | 0.1.17、versionCode 37。英語・日本語とも表示名はFolduo。従来と同じ署名で更新 |
| 実機での操作 | 内側ホームから実タップで電卓を起動しホームへ戻る操作を3回。各回でホームを前面・内側へ移動。長押しのアプリ選択、Folduo設定の表示も成功 |
| 前提 | 実機試験では補助処理から一時的に両画面を点灯。手で端末を開閉した最終試験は未完了 |
| 自動検査 | 単体試験32件成功。最終変更に関するエミュレーター試験14件成功。静的検査はエラー0件、警告34件 |
| 端末の整理 | 過去の別アプリと試験用アプリを削除。Folduoを標準ホームに設定 |
| 未確認 | 物理的な開閉後の継続操作、USBなしでの長時間動作、他のホームアプリでの同症状の解消 |

開閉の投影・ぼかし計算、細かな角度の取得経路は変更していません。実機のインストール済みAPKを取得し、ビルドした実機試験用APKとのSHA-256一致を確認しました。公開用APKとの比較は以下に記載します。

```text
ca652514a2e8934ecccdc082dc3ae355744ebb18862985fae02525f0e5e127e2
```

公開用APKはコミット `f81112a` から再ビルドしました。実機試験用APKとの差は `META-INF/version-control-info.textproto` のコミット情報のみです。DEX、マニフェスト、リソース、ライセンス素材は同一で、署名の一致も確認しました。公開ソース76ファイル、Git履歴、展開したAPKの秘密情報検査は検出0件。前面壁紙補助のプログラムは0.1.16の配布物と一致しています。

公開APKのSHA-256：

```text
cc411e05833ca6b73030145b3f32d2ad5f96c45242502ecefae3b5a627483ba2
```

0.1.17を実験版として配布します。実際の開閉を含む最終確認は未完了です。同じ症状が残る場合は、閉じた前面ホームからアプリを起動してください。個人のアプリ配置や実機の未加工ログは配布しません。

## 配布対象とライセンス

配布対象は自作ソース、ビルド定義、試験、壁紙の設定補助、文書、Gradle Wrapper、依存ライブラリのライセンス表示です。実機ログ、個人の画面、端末シリアル、署名の秘密鍵、ローカル環境設定、第三者の壁紙・動画・アプリは含めません。

配布APKは実験用のデバッグ署名を使っています。署名鍵は公開しません。Folduo 0.1.15と0.1.16のパッケージ識別子・署名は一致しています。自分でビルドした場合は署名が異なるため、配布版へ直接上書きできません。

自作部分はMITです。Shizuku API 13.1.5のMIT、実行時依存のApache 2.0、BSD 3-Clause、Boostの原文と表示をソースとAPKへ同梱しています。詳細と出典は[第三者のライセンス一覧](../THIRD_PARTY_NOTICES.md)を参照してください。

## 確認の限界

別の型番・OS、長時間のケーブルなし運用、すべてのアプリ、内側の純正操作バーの完全復元は未確認または未対応です。Shizuku停止の根本原因は未確定です。エミュレーター試験の成功は、Samsung独自の画面制御やすべての実機操作が正常であることを示しません。
